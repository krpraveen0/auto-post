# Agentic AI Engineering Course Index

Use this page as the Medium course landing/index article.

## Course Promise

This series teaches engineers how to move from prompt experiments to production-minded agent systems with tools, state, retrieval, evaluations, deployment gates, and rollback.

## Who This Is For

This is for software engineers and AI builders who have used LLM APIs and want a practical system design path for reliable agents.

## Lessons

1. What Makes an AI Agent Different from a Chatbot?
2. The Six Configuration Surfaces of an Agent
3. Building a Minimal Tool-Using Agent
4. Inside the Reasoning Loop
5. Handling Tool Failures Without Hiding Them
6. Designing a Self-Correcting Research Agent
7. RAG Is Not a Magic Truth Layer
8. Managing Context Before It Manages You
9. Building a Document-Grounded Agent
10. Why LLM Evals Are Different from Unit Tests
11. Building an Eval Gate for an Agent
12. Reading Eval Results Like an Engineer
13. Agent-as-Code: Versioning Behavior, Not Just Code
14. Promotion Pipelines for Agents
15. Capstone: Ship and Roll Back a Production Agent

## Final Project

By the end, the reader should have a versioned agent project with tool schemas, retrieval, evaluation gates, deployment promotion rules, and rollback documentation.
