# Course Series Workspace

Use this folder for Medium course-series planning artifacts.

Recommended files:

- `[series_slug]-intake.md`
- `[series_slug]-map.md`
- `[series_slug]-lesson-[part]-plan.md`
- `[series_slug]-index.md`

Draft individual lessons through the normal `medium/drafts/` workflow, then publish final lesson packages under `medium/publishing/`.

The daily Notion-first, Markdown-portable workflow is documented in
[`docs/automation/codex-daily-medium-course.md`](../../docs/automation/codex-daily-medium-course.md).
The workflow does not create office-document formats. Cross-platform release
requirements are in
[`docs/automation/global-technical-publishing-standard.md`](../../docs/automation/global-technical-publishing-standard.md).
