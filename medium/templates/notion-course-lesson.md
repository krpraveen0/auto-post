# Notion Course Lesson Page

Use this information hierarchy when copying a validated lesson into Notion. It
matches the repository Markdown and translates cleanly to a Medium draft.

```text
Title
One-sentence reader promise
Byline and AI-assistance disclosure
Navigation callout: Previous | Course index | Next

Concrete opening situation

Learning Outcomes
Before You Start
Mental Model
  Embedded explanatory visual
  Figure caption with the takeaway
Worked Example
Tested Environment
Exercise
Check Your Work
Retrieval Practice
  Two to four recall/application questions
  One transfer prompt
Recap
Next Lesson callout
Sources
```

## Notion Style Rules

- Use the article title as the page title; do not repeat it as an H1 block.
- Use H2 for the lesson arc and H3 only when a section genuinely needs grouping.
- Keep paragraphs short and place code beside the explanation it supports.
- Use one restrained callout for navigation and one for the next lesson.
- Embed the real visual and preserve its alt text and caption.
- Keep Sources as direct descriptive links; do not paste raw tracking URLs.
- Keep the byline and disclosure near the opening, matching the canonical
  Markdown and the destination platform's current requirements.
- Do not include internal score notes, prompts, or `[SOURCE NEEDED]` markers in a
  publishing-ready page.
- Read the page back after writing and compare its heading order, code, images,
  links, exercise, and sources with the canonical Markdown snapshot.
